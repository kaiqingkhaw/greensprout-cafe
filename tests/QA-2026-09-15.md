## Environment and limits

MySQL was initially stopped and catalogue requests failed. It was running again during verification. Both Apache and MySQL must run for the XAMPP site; a static file server cannot execute the PHP endpoints.

The temporary PHP preview needed a writable session directory. Its first HTTP test run failed CSRF validation because the sandbox could not write XAMPP's session directory; setting a preview-only session directory resolved this without changing application authentication.

This is a portfolio demo with simulated card/wallet payments. These checks do not certify every device, browser, screen reader or production scenario. GitHub Actions is configured but has not run on GitHub yet.
